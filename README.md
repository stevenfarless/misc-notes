# misc-notes

Research notebook for theological and comparative-religion studies. Debate documents present the strongest cases for competing positions, critiques, rebuttals, and the questions on which disagreements turn.

## Reading the notebook

Open the published reader:

**https://stevenfarless.github.io/misc-notes/**

The reader provides searchable navigation by subject and category, and displays the original Markdown articles in a clean reading layout. It is hosted by GitHub Pages and requires no installation, download, folder selection, or local server.

## Adding and editing studies

The article catalog and website are rebuilt automatically by GitHub Actions whenever changes are pushed to `main`.

To add a study:

1. Create a new `.md` file in the appropriate subject folder.
2. Add a title and optional tags in YAML front matter.
3. Commit or push the change to `main`.

To revise or remove a study, edit or delete its `.md` file and push the change. The catalog updates during the same automated deployment.

Example front matter:

```yaml
---
title: Calvinism vs. Arminianism
tags: [soteriology, grace, election, free-will, predestination]
related:
  - theology/anthropology/monism-vs-dualism.md
---
```

Use canonical tags listed in [TAGS.md](TAGS.md). The tag index, README file tree, article manifest, and published site are generated automatically. The website reads the original Markdown files, so there are no separate article copies to maintain.

## Document structure

Debate files generally include a table of contents, definitions, arguments, critiques, rebuttals, and selected bibliography. Topic studies gather biblical texts, historical interpretation, and scholarly discussion around focused subjects.
